## ✍️ 문서 스튜디오 (신규 수익 요소 — 별도 운영)

`studio.html` — 법률 문서를 폼 입력만으로 자동 생성하는 문서 작성기.
킷 패키지와 별개로, 구매 시점에 생성되는 맞춤 문서의 무워터마크 출력을 판매합니다.

문서 타입 × 출력 언어:

| 문서 | KO | EN | JA | ZH |
| :--- | :-: | :-: | :-: | :-: |
| 사이버 명예훼손·모욕 고소장 | ✅ | — | — | — |
| 내용증명 · Demand Letter | ✅ | ✅ | ✅ | ✅ |
| 경고장 · Cease & Desist | ✅ | ✅ | ✅ | ✅ |
| 차용증 · Loan Agreement | ✅ | ✅ | ✅ | ✅ |
| 프리랜서 용역계약서 · Services Agreement | ✅ | ✅ | ✅ | ✅ |
| 합의서 · Settlement Agreement | ✅ | ✅ | ✅ | ✅ |

- **결제 자동화(선택)**: `studio.gumroadUrl`/`gumroadProductId`를 설정하면 Gumroad 라이선스 키로 무인 잠금해제 — 수동 코드 발급 불필요
- **법정 표시**: `legal.html` — 약관/개인정보/환불/사업자정보 (판매 개시 전 `입력필요` 항목을 실제 사업자 정보로 교체 필수)
- **무료**: 화면 미리보기 (워터마크 포함, 인쇄는 잠금 해제 후에만 가능)
- **유료**: 건별 ₩9,900~14,900 (문서별 차등 — `studio.prices`로 오버라이드) 또는 전 문서 무제한 패스 ₩29,900 (`studio.passPriceKrw`) — 결제 확인 후 해제 코드 발급 → 원본 인쇄/다운로드
- **전자서명**: 계약서류(차용증·용역계약서·합의서)는 브라우저 내 서명 패드로 서명 이미지 박제 지원 — 편의용 서명, 공인전자서명 아님 (서명 이미지도 브라우저에만 저장)
- **문서 식별 해시**: 렌더링된 문서 하단에 SHA-256 해시 자동 표기 (내용 변조 여부 확인용, 법적 효력 보증 아님)
- **내문서함**: 작성 문서를 localStorage에 최대 20건 저장·재열람 (서버 미사용)
- 입력 정보는 전부 브라우저 안에서만 처리 (서버 전송 없음)
- 해제 코드 발급(운영자): 페이지 콘솔에서 `OmniStudio.mintCode("주문번호-이메일")` → `{code, digest}` 반환. 반환된 **digest를 `studio.unlockDigests`에 추가·배포한 뒤** code를 고객에게 발급 (digest 미등록 코드는 검증 실패)
- 예비 코드 8종이 `settlement_config.js`의 `studio.unlockDigests`에 등록되어 있음 — 재고처럼 1건씩 배분 가능
- ※ 코드 검증은 정적 사이트 한계상 소프트 게이트 — 실질 통제는 결제 확인 후 코드 발급 절차
